Privacy Policy

Last updated: 6 October 2026

This policy explains how the Little Lantern Stories publishing tool (“the app”) handles information. The app is a private automation that uploads our own original animated videos to our own YouTube channel. It is operated by the owner of the GitHub repository SAGARKanuru/kid_stories.

Who uses the app

Only the channel owner signs in to the app. It does not offer sign-in, accounts or any service to the public, and it is not used by children.

Google and YouTube data we access

With the channel owner’s permission, the app uses the YouTube Data API to:

  • upload videos, titles, descriptions, tags and thumbnails to the owner’s channel;
  • add uploaded videos to the owner’s playlists.

It does not read, store or share viewers’ information, comments, subscriber lists, watch history, email, contacts or any other Google account data.

How credentials are stored

The OAuth sign-in token is stored as an encrypted secret in the owner’s GitHub repository and is used only by the owner’s automated workflow to upload videos. It is never shared with anyone else.

Viewers and children

Videos are marked “Made for Kids” on YouTube. This app collects no personal information from anyone who watches the videos, including children. Viewing on YouTube is governed by YouTube’s Terms of Service and the Google Privacy Policy.

Use of Google API data

The app’s use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. We use the YouTube API Services, and by using this app you also agree to YouTube’s Terms of Service.

Revoking access

The channel owner can revoke the app’s access at any time at myaccount.google.com/permissions. When access is revoked, the stored token stops working and no further uploads can be made.

Changes

If this policy changes, we will update this page and the date above.

Contact

Questions about this policy: open an issue at github.com/SAGARKanuru/kid_stories/issues.
